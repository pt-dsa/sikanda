# Roadmap dan Checklist Revisi SIKANDA

## 1\. Aturan Ketat SIKANDA

1. Setiap Seluruh Perubahan harus terupdate di local E:\\sikanda  
2. Setiap Seluruh Perubahan harus terupdate(push repository) github [https://github.com/pt-dsa/sikanda-app/actions](https://github.com/pt-dsa/sikanda-app/actions)  
3. SIKANDA harus responsif pada semua device (mobile first).  
4. Setiap perubahan pada SIKANDA harus terupdate juga pada PWA.  
5. SIKANDA harus tetap memenuhi unsur Keamanan tingkat tinggi.  
6. SIKANDA harus lulus security testing.  
7. Seluruh teks Judul, Tittle,subtittle, Judul Header Tabel dan keterangan lainya dibuat tebal (bold).  
8. Judul Menu pada Panel SIKANDA seluruhnya dibuat tebal (bold).

## 2\. Revisi Menu Dashboard

- [ ] Card “Distribusi Pendidikan” urutkan Chart berdasarkan jenjang pendidikan. mulai dari SMP sampai S-2/STRATA II.  
- [ ] seluruh teks Judul, Tittle,subtittle dan keterangan lainya harus cetak tebal (bold).  
- [ ] seluruh Card dan chart harus rapih dan proporsional ukurannya.

## 3\. Revisi Menu Data ASN / PPPK

- [ ] Judul Card “Aset Terverifikasi” rubah menjadi “Pegawai dengan Aset Terverifikasi”  
- [ ] Judul Card “Perlu Verifikasi” rubah menjadi “Pegawai dengan Aset Perlu Verifikasi”  
- [ ] Judul Card “Tanpa Aset” rubah menjadi “Pegawai Tanpa Aset”.  
- [ ] Hilangkan fitur “Capture Layar”.  
- [ ] Judul pada Header Tabel Pegawai dibuat Tebal (Bold).

## 4\. Revisi Menu Buku Penjagaan

- [ ] Pebaiki bug lambat tampil modal pada fitur “Pengaturan Agenda”.  
- [ ] Rubah judul fitur “Refresh” menjadi “Sinkronisasi”.  
- [ ] Rubah Istilah “Jatuh Tempo” menjadi “Tenggat Waktu”. 

## 5\. Revisi Menu Data Kendaraan

- [ ] Perbaiki bug “Tampilkan Data” pada informasi contoh “131 kendaraan belum memiliki data kondisi” ketika di klik belum menampilkan data. dan seharunya ketika di klik kembali maka tampil seperti semula.  
- [ ] Rapihkan tabel agar proporsional dan judul Header dibuat kapital dan tebal (bold).  
- [ ] pada detail kendaraan dan Edit Kendaraan, buatkan minimap menampilkan peta lokasi kendaraan.

## 6\. Revisi Menu Inventaris

- [ ] Perbaiki bug “Tampilkan Data” pada informasi contoh “140 inventaris belum memiliki data kondisi” ketika di klik belum menampilkan data. dan seharunya ketika di klik kembali maka tampil seperti semula.  
- [ ] Rapihkan tabel agar proporsional dan judul Header dibuat kapital dan tebal (bold).  
- [ ] pada detail Inventaris dan Edit Inventaris, buatkan minimap menampilkan peta lokasi kendaraan.

## 7\. Revisi Menu Rekap Laporan

- [ ] fitur cetak halaman, Tambahkan watermark logo SIKANDA dengan tampilan proporsional pada setiap halaman tanpa mengganggu pembacaan data hasil cetak.

## 8\. Revisi Menu Kelola Akun

- [ ] Tabel data pegawai, urutan seharusnya Nama Pegawai \- NIP \- Status Pegawai \- Email \- Peran \- Status \- Aksi.  
- [ ] Judul pada Header Tabel dibuat Tebal (Bold).

## 9\. Revisi Menu Data Cleansing

- [ ] Seluruh Data Cleansing dibuat dalam bentuk Tabel yang dapat di scroll.  
- [ ] Cleansing “Kondisi Aset Belum Diisi” klik “Perbaikan” seharusnya muncul modal popup CRUD Edit Kendaraan, tetapi menu tetap di Data Cleansing tidak berpindah ke menu Data Kendaraan. ini penting agar Administrator dan Pimpinan tidak perlu bolak-balik kembali ke menu Data Cleansing. revisi ini terapkan juga pada bagian Cleansing Pegawai dan Cleansing Nama Pengguna Aset.  
- [ ] Tebalkan judul Header kolom.
